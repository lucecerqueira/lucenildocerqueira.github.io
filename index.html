Áreas de Especialização

Pesquisa Científica e Desenvolvimento Tecnológico

Ciência de Dados e IA em Saúde

Desenvolvimento de modelos preditivos, classificação diagnóstica de sinais eletrofisiológicos (ECG, VCG e EMG), regulação autonômica, vigilância epidemiológica e análise espacial em oncologia.

Engenharia de Dados e Sistemas Web

Arquitetura de pipelines ETL de alto desempenho para grandes bases governamentais (DATASUS/SIM) e construção de aplicações analíticas e painéis interativos em produção.

Biomecânica e Fisiologia Computacional

Modelagem matemática não-linear da cinética cardiorrespiratória (VO2), análise cinemática da locomoção, sincronização cardiolocomotora e tempo de reação neurocognitiva.

Projetos e Sistemas em Destaque

Soluções Aplicadas em Engenharia Biomédica e Data Science

Classificação Diagnóstica de ECG / VCG 3D

Pipeline de processamento de sinais biomédicos e inteligência artificial para detecção de Infarto do Miocárdio e alterações de ST-T via reconstrução espacial 3D do vetorcardiograma.

Python Scikit-Learn Keras Processamento de Sinais

Vigilância Oncológica e Pipeline ETL (SIM/DATASUS)

Ecossistema para extração, descompactação nativa em C, transformação e carga de microdados de mortalidade integrado a painel geoespacial interativo.

R / Shiny Python Django PostgreSQL C

Apoio à Decisão Clínica (Lesão Renal Aguda)

Aplicação web para estratificação de risco clínico de rabdomiólise e lesão renal aguda, equipada com operação offline resiliente e geração automatizada de laudos em PDF.

Python Django PostgreSQL Modelagem Clínica

Plataforma Analítica para Eco-hidrologia

Sistema web para gerenciamento de dados ambientais, modelagem estatística e monitoramento de indicadores de qualidade da água para consumo humano.

Python Django Pandas Plotly

NeuroPulse — Tempo de Reação Cognitiva

Aplicação de alta precisão temporal para avaliação neurocognitiva e biomecânica executada diretamente no navegador via WebAssembly com latência mínima.

Rust WebAssembly Leptos
